This repository contains the frontend code (CSS, JS, HTML and XSLT) for Legislation.gov.uk, as running on 22 April 2022. This includes the data transforms that take the base data format (CLML) to our default XHTML display format, and the associated CSS and JavaScript. It also contains transforms to create the Akoma Ntoso XML (LegalDocML).

For more information about the data, please refer to the [legislation.gov.uk](https://www.legislation.gov.uk) data documentation.
